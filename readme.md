# 🎙️ Web Speech API - Voice Recognition Demo

Uma aplicação web que utiliza a **Web Speech API** para converter fala em texto em tempo real, utilizando reconhecimento de voz em português (pt-BR).

Este projeto foi desenvolvido para explorar as capacidades nativas dos navegadores modernos e demonstrar a utilização da Speech Recognition API através de JavaScript puro.

---

## 📖 Sobre o projeto

A aplicação permite iniciar o reconhecimento de voz, transcrever automaticamente o áudio capturado pelo microfone e exibir mensagens de status durante o processo.

O projeto demonstra como integrar recursos nativos do navegador sem a necessidade de bibliotecas externas.

---

## ✨ Funcionalidades

- 🎤 Captura de voz pelo microfone
- 📝 Conversão de fala em texto em tempo real
- 🇧🇷 Suporte ao idioma Português (Brasil)
- ▶️ Iniciar reconhecimento
- ⏹️ Parar reconhecimento
- 🗑️ Limpar transcrição e histórico
- ⚠️ Tratamento de erros da Web Speech API

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- Web Speech API
